# Portofolio Muhammad Lutfi Nanang Setiawan

Portofolio Muhammad Lutfi Nanang Setiawan: Media Officer dan Public Relations di Masyarakat Ekonomi Syariah (MES), serta jurnalis dan penulis.

**Lihat situs:** https://alltruis.github.io/Portofolio-Lutfi/

## Isi situs
- **Public Relations:** press release dan berita, copywriting Instagram, siniar dan video Smart Syariah, serta Artikel X dan MES Quote, lengkap dengan angka capaian bersumber.
- **Karya Online:** esai dan opini yang terbit di media daring.
- **Karya Cetak:** majalah, jurnal, buletin, dan laporan riset, termasuk video dokumenter.
- **Tentang dan kontak:** profil singkat, serta tautan LinkedIn dan media sosial.

## Struktur repositori
- `index.html`: seluruh halaman (HTML, CSS, dan JavaScript dalam satu berkas).
- `gambar/`: gambar situs, dibagi per jenis (`pr/`, `rubrik/`, `karya/`, `umum/`).

## Catatan
Situs statis tanpa proses build, ditayangkan lewat GitHub Pages. Angka capaian bersumber dari Google Analytics 4 MES dan Meta Business Suite MES, dengan keterangan sumber di setiap kartu.
